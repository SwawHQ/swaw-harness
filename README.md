# Swaw Harness

**一座由人与 Agent 共同建设的命令工厂。**

你提出需求，与 Agent 一起探索、实现和验证，把成熟的解法做成下一次可以直接调用的命令。

每解决一类问题，就为自己添一件工具。随着使用、组合和改进，这些命令逐步长成一个人或团队自己的技能体系。

这就是 Swaw Harness 的初心：**让解决问题的过程，持续生产解决问题的能力。**

我们想让 Codex、Claude Code 这样的 Agent 更多地充当“编译器”：将人的意图逐步物化为代码、技能声明和执行模块。已经稳定的步骤交给程序运行，新的问题和变化继续交给人与 Agent 协作解决。

例如，设想你与 Agent 打磨出一套日报流程：收集数据、计算指标、生成报告。我们希望这次工作最终留下一个命令：

```powershell
alice.exe reports/daily
```

明天直接运行，需求变化时继续改进。它还可以成为更大工作流的一部分。

为了让这样的命令能够不断积累，Swaw Harness 正在建设：

- **长在文件树里的技能图。** 用目录组织和寻址技能，用 `skill.toml` 声明执行模块，用 `help.md` 说明用途。命令背后的定义可以直接阅读、编辑和管理版本。
- **独立发布的执行模块。** Module Release 保存不可变、可验证的模块版本，让命令落到具体的执行产物上。
- **负责执行的本地运行时。** Core Host 解析技能、监督模块运行，并留下运行记录，让成熟能力能够直接使用。
- **从技能走向工作流的组合机制。** 探索通过技能子树、显式依赖和执行计划，把已有能力组织成更大的能力。

**命令是入口，技能是积累，工厂要能持续生长。**

项目目前处于 **pre-alpha**，已实现 Windows 上的技能树查看与单节点执行，正在向技能组合与工作流推进。我们会一边建设，一边公开记录设计、取舍和实践。

欢迎带着你想反复完成的事情，一起探索：**它能不能成为下一条命令？**
